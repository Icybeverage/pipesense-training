# PipeSense track strategy

## Apply

1. **Best Loop Design** — primary track. PipeSense visibly executes Observe →
   Coach → Adapt → Retry → Evaluate. The selected intervention changes the next
   simulation attempt, and the verified demo records a score improvement from
   0 to 100.
2. **Best Use of Weave** — primary sponsor track. Each practice cycle is a
   `pipesense/attempt-loop` trace with nested observer, coach, inference and
   evaluator operations. The app includes a dedicated W&B story view with the
   live provider, project, attempt history, intervention and score delta.
3. **Most Production-Ready** — strong supporting track. The browser simulation
   is deployed with server-side secrets, deterministic scoring, live-service
   status, graceful offline coaching, an opt-in voice agent and a complete
   mouse/keyboard fallback for camera issues.
4. **Best Social Media Demo** — strong supporting track. The public 62-second
   H.264/AAC demo has conversational Maya narration, a clear failure-to-success
   arc and ends on the W&B proof page.

## Do not apply yet

- **Best Use of ARIA** — ARIA is not in the shipped interaction or agent path.
- **Best Use of TypeSafe AI** — the shipped FastAPI/JavaScript stack does not
  demonstrate the sponsor technology.
- **Best Use of marimo** — the repository includes an attempt-metrics analysis
  notebook, but it is an ancillary developer tool rather than a meaningful part
  of the learner experience or adaptive loop. Entering would weaken the pitch.

The four selected tracks share one proof story instead of requiring speculative
features: a realistic task fails, W&B observes and adapts the instruction, the
learner retries, deterministic scoring verifies success, and Weave preserves
the evidence.
